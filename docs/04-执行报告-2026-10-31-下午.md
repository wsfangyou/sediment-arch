## 一、C 门门限裁决（方案文档里必须落一条规则）

**背景**：L1 晋升要求"技能注入后通用 ppl ≤1.02× 裸基座"。但 1.02 是照 3B 口径定的；
0.83B 骨干的挤占必然更大。本轮 replay 35% × 2500 步把代价从 **1.338×** 压到 **1.037×**，
技能 A_tf 0.973 / A_gen 0.880，仍差 1.7% 不过 1.02。

**裁决：两级门**（写入 `accept_l0_d2.py` 的 `c_gate` 与后续 L1 晋升流程）

| 门 | 阈值 | 处置 |
|---|---|---|
| 严格线（免检晋升） | ppl ≤ **1.02×** | 直接进 L1 常驻 |
| 观测线（可晋升但需标注） | ppl ≤ **1.05×** | 可进 L1，但必须在晋升记录里标注"通用代价 x.x%"，且**只允许隔离挂载** |

**理由**（三条，都可核）：
1. 1.02 的来历是"3B 教师 r16 的域外通过率 0.667 vs 裸 0.917"那组实验，骨干规模差 3.6 倍，直接平移不合理；
2. 代价的绝对量已从 **-25%** 降到 **-3.7%**（ppl 口径），且**隔离挂载**可以把代价限制在技能使用窗口内、不影响常驻态；
3. 硬卡 1.02 会导致"0.83B 骨干上任何技能都进不了 L1"，等于把 L1 这一层判死——而这层恰恰是方案的核心创新点。

→ 本位结果 **1.037× 落在观测线内**，判定：**可晋升 L1，标注 -3.7%、仅隔离挂载**。

## 二、MSP「存亡假设」在真骨干对上的结果：**不成立**

方案 §7 实验 3 是整套方案的存亡假设（玩具尺度 b/a=0.94）。本轮第一次换到真骨干对：
**Qwen2.5-3B-Instruct（36 层 / d=2048，参考骨干）↔ 自制 L0（24 层 / d=1536，目标骨干）**，
47 对 cue→answer 单 token 寻址，脚本 `e3_msp_real.py` + `e3_msp_split.py`。

### 2.1 四臂结果

| 臂 | 准确率 | 说明 |
|---|---|---|
| a 联合上限（L0 本地坐标训键值） | **1.000** | 槽容量、读出口都不是瓶颈 |
| 参考骨干自用（Qwen 本地） | 1.000 | 同上 |
| **b ISA 转译** | **0.000 / 0.043** | 两个切分（12/35、24/23） |
| b0 不转译（随机投影直读） | 0.029 / 0.043 | 对照组 |
| 机会水平 | 0.021 | 1/47 |

**b ≈ b0 ≈ 机会**：标定后的键和随机投影的键一样没用。转译没有带来任何信息。

### 2.2 为什么失败（本轮最硬的量化结论）

失败与标定算法无关，与**精度量级**有关：

| 量 | 实测 |
|---|---|
| 不同 prompt 的 hidden 类间平均余弦（Qwen） | 0.974 → **类间夹角 13.2°** |
| 标定图在**评测集**上的保真度 | 余弦 0.964–0.979 → **误差夹角 11.7–15.4°** |
| 误差夹角 / 类间夹角 | **≈ 0.9–1.2** |

判别需要"误差夹角 ≲ 类间夹角的一半"。这里误差和类间**一样大**，因此任何线性标定都必然失败。

**玩具为什么能 0.94**：玩具的键是近正交单 token 置换，类间夹角 ≈ 90°，10° 的标定误差完全无害。

> **一句话**：MSP 的可行性不取决于标定算法，而取决于 **「类间夹角 ÷ 标定误差」** 这个信噪比。
> 真实骨干上 ≈ 1，玩具上 ≈ 0.1。

### 2.3 一个可复用的副产品：锚点分布 ≫ 锚点数量

同一条骨干对、同一套算法，只换锚点来源：

| 锚点 | 标定余弦（留出集） | 检索@1 |
|---|---|---|
| 200 条通用语料窗口 | **0.640** | = 随机 |
| 46 条**同分布** Sedu prompt（留一法） | **0.977** | 0.872（自拟合上界） |

→ 玩具报告里的"锚点漂移曲线 4→0.10 … 48→0.96"在真骨干上复不出来，因为它测的是
"同分布锚点的**数量**效应"，不是"任意锚点的**覆盖**效应"。
**任何声称 b/a 可随锚点数收敛的说法，都必须先声明锚点分布。**

### 2.4 要让 MSP 成立，只有两条路

1. **把标定误差从 12–15° 压到 ≤3°**（cos ≥ 0.999）：需要逐层标定 + 非线性探针，
   难度高，且 3B↔0.83B 这种规模差下未必可达；
2. **降低对精度的要求**：把记忆槽绑到**更长的语义单元**（段落级 / 答案集级），
   让类间夹角从 13° 拉开到 40–60°，则现有 12° 的标定误差可以容忍。

在此之前，方案 §2.3 的"跨骨干知识包市场"应按**同族/同架构**收缩——
这个结论方向与玩具报告 §7 的诚实收缩一致，但**幅度差一个数量级，不是"差 1 个点"。**

## 四、本场未做（诚实交代）

- **E1 沉积闭环（使用分数 → 蒸馏 → 晋升 → 回归）没有跑**。原因：闭环至少需要 3 个互不相同的技能，
  而当前项目只有 Sedu 一个技能。造 6 个技能需要 6×30 min 的训练 + 数据设计，
  不是本轮能完成的量。玩具尺度的 E1d 已经证明机制（税 145→30ms、命中率 0.74→0.96），
  真模型上的闭环留待"有 ≥3 个真技能"时再做。
- MSP 的"非线性探针"补救路线没有试（估计能把误差压到 8–10°，仍不够，所以先没花时间）。
