### §2.4 MSP 跨骨干：真骨干上不成立（2026-10-31 下午）

方案 §7 实验 3（存亡假设）第一次在真骨干对上重做：Qwen2.5-3B（参考）↔ 自制 L0（目标），
47 对 cue→answer 单 token 寻址。

| 臂 | acc |
|---|---|
| a 联合上限（L0 本地） | 1.000 |
| b ISA 转译 | **0.000 / 0.043**（两个切分） |
| b0 不转译 | 0.029 / 0.043 |
| 机会 | 0.021 |

机制（可复用）：**类间夹角 13.2°（hidden 余弦 0.974）vs 标定误差夹角 12–15°（cos 0.964–0.979）
→ 误差 ≈ 类间，任何线性标定都不可能区分。** 玩具 0.94 是因为键近正交（90°）。
判据应改为信噪比 **类间夹角 ÷ 标定误差 ≥ 2**，而不是"锚点数够了就行"。

副产品：锚点**分布**比数量重要（同分布 0.977 / 通用语料 0.640）。
救法只有两条：标定误差压到 ≤3°（cos≥0.999，难），或把记忆槽绑到更长语义单元（类间拉开）。

→ 方案 §2.3「跨骨干知识包市场」应收缩为**同族/同架构**，且这不是"差 1 个点"而是差一个数量级。

### §2.5 补充（2026-10-31 凌晨）：L1 沉积物的真实代价 —— 卡住晋升的是通用回归，不是体积

在 L0 上首次端到端测「训技能 LoRA → 秩截断 → 复测行为 + 验证集 ppl」
（`scripts/e1_l1_deposit.py` / `e1_cgate.py` / `e1_cgate_rank.py`，数据 `l0_acceptance/e1_*.json`）：

| 秩 | 体积 | A_tf | 行为保真 | 通用 ppl（98k token） | C 门 1.02 |
|---|---|---|---|---|---|
| 16（教师） | 24.2 MB | 0.727 | 1.000 | 76.17 = **1.338×** | ❌ |
| 8 | **12.1 MB** | 0.722 | 0.992 | 75.70 = 1.330× | ❌ |
| 4 | 6.0 MB | 0.722 | 0.992 | 74.04 = 1.301× | ❌ |

三条结论（都已写进 `D:/Qwen-works/沉积架构实现可能性评估-2026-10-31.md`）：

1. **秩截断几乎免费**（r2 都不掉点）→ L1 体积预算在本模型上过剩：r8 12.1MiB，1GB 装 84 个。
2. **真正的门是 C 门**：挂一个 80 词封闭技能，通用 ppl 涨 22–34%。**且训得越久越糟**，
   所以"多训几步把 D2 打过去"会把 C 门推得更远 → 必须先做 **replay 混采（如 20% 通用中文）**。
3. **L1 的"常驻"必须定义为"驻留 + 隔离挂载"，不能合并进 L0**（否则永久 -25% 通用能力）。
4. 方法学：单段落 ppl 测出 1.043（看似可过），98k token 验证集是 1.338 —— **C 门必须用验证集口径**。
