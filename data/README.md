# 技能数据集

三个自造语技能，格式完全一致，**程序可判分**（判分器见 `scripts/accept_l0_d2.py` 的 `gen_acc`）。

| 技能 | 训练 | holdout | 说明 |
|---|---|---|---|
| Sedu | 4,800 | 600 | 早期主技能，80 词词典 + 三种句法 |
| Nuri | 2,400 | 300 | 为多技能干扰实验新造，音系与词表完全不同 |
| Tavi | 2,400 | 300 | 同上，另一套音系 |

每条样本的字段：

```json
{"id": "r0", "task": "s2c", "q": "把这句Sedu语翻译成中文：gade ke gade", "a": "马和马"}
```

`task` 三选一，判分方式不同：

| task | 问句 | 判分 |
|---|---|---|
| `s2c` | 把这句{X}语翻译成中文：… | 整句精确匹配 |
| `c2s` | 把这句中文翻译成{X}语：… | 整句精确匹配（空白归一化） |
| `gloss` | {X}语词“…”用中文怎么说？ | 答案包含在该输出中即可 |

`sedu_lexicon.json` 是 Sedu 的词典（中文 ↔ Sedu 词），用于生成数据与构造 MSP 探针的锚点。

重新生成：`python scripts/gen_multi_skill.py`（Nuri / Tavi，固定种子，可复现）。
