# Sediment-LLM 原型（沉积架构 · 可运行实现）

《低显存大模型流畅运行方案——沉积架构》的软件原型：验证"小显存双向流动推理架构"中  
**调度层与迁移机制**的真实行为。纯 Node.js，零外部依赖，自带线性代数（矩阵乘/岭回归/  
PCA/量化/高斯消元全部真实计算）。

```
node src/index.js            # 全部实验 + 端到端演示
node src/index.js band       # 报告 §2.1 推论复算（地基自检）
node src/index.js sediment   # 实验1：沉积闭环
node src/index.js gene       # 实验2：L4 基因化保真扫描
node src/index.js msp        # 实验3：MSP 跨骨干转译（存亡假设）
node src/index.js arbit      # 实验4：相图 + 竞价仲裁
```

## 实测结果（本机运行原样，非估算）

**E-band**：推论1 稠密逐 token 过 PCIe = 5.68 tok/s（报告 5.7 ✅）；x8 = 2.27；  
NVMe 串联流式 = 0.91（灾难区 ✅）；推论3 300MB 会话级加载 96.6 ms、摊薄 0.073 MB/token ✅。

**E1 沉积闭环（200 轮）**：加载税 p95 从 195ms → 30ms（**降 84.6%**）；发生搬运的轮次  
42%→16%；晋升 4 次（蒸馏保真均值 97.8% ≥ 质量门 95%）；2 个零使用技能基因化为  
KB 级潜码（库足迹 8.2KB）；任务分不降反升（0.950→0.979，L1 附加增益所致）。  
→ **沉积闭环成立**（在代理质量模型下）。

**E2 基因化（200 技能库）**：诚实负结果——技能库从 10 扩到 200 后，共享码本重建保真  
全部 K <0.95（K=12 仅 0.79），尽管压缩率 6.3×、最近邻命中率 1.0。  
→ **对应方案 N5 风险成真**：码本容量随库规模增长退化，L4 只能做"身份检索"（命中哪个  
技能），不能做"参数重建"；基因化必须保留原文件兜底，或转向按域小码本/真超网络。

**E3 MSP 跨骨干转译（存亡假设）**：ISA 转译达联合上限的 **91.5%**（朴素不转译仅 0.136，  
接近随机 0.1）。漂移曲线随锚点数单调上升（k=4:0.18 → k=32:0.33），且锚点恰定时仍未饱和。  
→ **判定"部分成立"**：最小寻址 ABI（锚点标定）能桥接 91.5%，未过 95% 线；  
与报告 C.4"共训锁定"的对抗中，ISA 化显著可行但标定精度（锚点数量/噪声）是新的瓶颈轴。

**E4 相图与仲裁**：静态驻留只过 11/28 个（插件尺寸×上下文）组合；启用"KV 低精度化+  
外移+插件尺寸准入"的竞价仲裁后过 **22/28**，仲裁器在持续压力下稳定收敛且决策全日志。  
→ 中粒度带（0.5–2GB）在 6GB 卡上**可运营**的调度前提成立。

**端到端演示**：空闲峰值 4.06GB；300MB 冷/热插件加载均被 prefill 隐藏；  
2GB"大脑插件"正确落入 OOM——实证方案 D.6.1"不消除峰值约束"。

## 诚实边界（重要）

1. **没有真实 LLM**：质量用"能力向量余弦"代理，蒸馏损失注入高斯噪声假设 σ=0.03。  
   实验验证的是**调度/迁移机制的动力学与物理预算**，不是模型质量。真实质量结论需要  
   接 llama.cpp/KTransformers 跑方案 §7 的原实验。
2. **骨干间关系建模为线性映射+标注噪声**（玩具尺度）。E3 的 91.5% 是对"机制形状"的  
   检验，不能外推到真实 Transformer 骨干——真实情况可能显著更差（共训锁定假设）。
3. 带宽数字全部取自报告标称区间中值，需按具体 SKU 实测校准（报告 §2.1 同样要求）。
4. 快权重在线回写（通道1）本原型未实现——它依赖真实训练栈，超出"调度层验证"范围。

## 结论与下一步

原型跑通后，方案的四条主张得到分级裁决：

- 沉积闭环（§2.2 通道2/3 + L1 预算）：✅ 机制成立，TTFT 税降 84.6%；
- 中粒度竞价仲裁（§3）：✅ 11/28→22/28；
- MSP-ISA 转译（§2.3）：⚠️ 91.5%，部分成立——锚点标定协议值得继续做，但需真实骨干验证；
- L4 基因化（§2.4）：❌ 共享码本方案在库规模下失败——需要改为真超网络或按域码本（这本身  
  是一个有价值的发现：它把"生成式插件"从省磁盘文件的手段修正为必须保证生成质量的组件）。
